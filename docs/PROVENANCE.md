# Provenance

All source material derives from **U.S. Department of Energy OSTI** public records
(https://www.osti.gov). x-Cards are machine-extracted summaries of research resources
described in those papers; review articles are LLM-synthesized from the papers' own text
with inline [OSTI:id] citations back to the source records.

- Corpus universe: 234,705 papers (Journal Article + Conference + Technical Report).
- Extraction/synthesis models: qwen3.8-27b (farm), Argo Sonnet (aggregator).
- Zero-hallucination policy: emails/URLs/versions recorded only when observed in source
  text, a sibling card, or a verified contact DB — never pattern-constructed.

No private network details (Tailscale 100.x, LAN IPs, credentials) should appear in this
repo. Public endpoint references use the Tailscale Funnel hostname only.
